# Beyond Benchmark Rankings: Information-Aware and Risk-Aware Optimization
# of Large Language Model Ensembles

# Dependency Manifest
# 
# This requirements.txt pins the complete dependency surface for a production-grade
# implementation of the FMEC (Fusion-based Model Ensemble Composition) framework.
# 
# The framework performs:
# • Multidimensional error taxonomy with covariance-aware risk estimation
# • Permutation-based Monte Carlo Shapley estimation for marginal utility
# • Outcome-based conditional mutual information (CMI) for informational novelty
# • Budget-feasible greedy submodular optimization for ensemble selection
# • Three-level nested cluster bootstrap for hierarchical variance decomposition
# • Pre-registered econometric hypothesis testing with Holm-Bonferroni FWER control
# 
# Author: CS Chirinda
# License: MIT
# Version: 1.0.0
#

# --------- Python Version & Environment --------- 

# This implementation targets Python 3.9–3.12 (inclusive).
# Pin your interpreter: python==3.9.* or python==3.10.* or python==3.11.* or python==3.12.*
# Rationale: 
#  • Python 3.9+: concurrent.futures stability, PEP 604 union type hints, importlib.metadata
#  • Python <3.13: LTS support for production; 3.13 is cutting-edge and not yet battle-tested
#            in distributed environments with ProcessPoolExecutor + pickle.

# --------- Core Scientific Computing Stack --------- 

# NumPy 1.24+: Dense tensor operations, random number generation (numpy.random.Generator),
# linear algebra (eigendecomposition, Cholesky), and stable pickle serialization of 
# Generator objects for reproducible Dirichlet sweeps across process boundaries.
numpy>=1.24.0,<2.0.0

# Pandas 2.0+: High-performance DataFrames, groupby hierarchies, multi-index operations,
# and robust handling of heterogeneous task-by-model results tables. Used for outcome
# tensor assembly, stratified bootstrap resampling, and variance-component reporting.
pandas>=2.0.0,<3.0.0

# SciPy 1.13+: Stable implementation of:
#  • scipy.stats.bootstrap with method='bca' for BCa confidence intervals
#  • scipy.stats.permutation_test for Spearman IG–MEC coupling validation (H2)
#  • scipy.stats.norm for z-score transformation in risk budgeting
#  • scipy.linalg for spectral decomposition and condition-number diagnosis
#  • scipy.optimize for Ledoit-Wolf shrinkage targeting and linear-program solvers
#    (future: knapsack/submodular-constrained selection via scipy.optimize)
scipy>=1.13.0,<2.0.0

# Scikit-learn 1.4+: Machine-learning utilities for preprocessing, reliability metrics, and 
# statistical testing:
#  • sklearn.preprocessing.StandardScaler for outcome normalization
#  • sklearn.impute.SimpleImputer for handling sparse adjudication results
#  • sklearn.cluster.KMeans for adjudication coherence diagnostics
#  • sklearn.metrics.cohen_kappa_score for inter-rater reliability on human audits
#  • sklearn.covariance.LedoitWolf (future: shrinkage targeting)
scikit-learn>=1.4.0,<2.0.0

# --------- Visualization & Publication --------- 

# Matplotlib 3.8+: Publication-grade 2D plotting, constrained_layout for multi-panel figures,

# Seaborn 0.13+: High-level statistical visualization built on Matplotlib.

# • NumPy 1.24+ introduced improved pickle serialization for numpy.random.Generator
#   objects, critical for deterministic parallel dispatch via ProcessPoolExecutor.

#   stabilized multi-index groupby for hierarchical bootstrap resampling.

#   permutation_test, which are essential for econometric hypothesis testing (H1–H5).

# • Scikit-learn 1.4+ includes stable Cohen's κ implementation and modern
#   preprocessing pipelines for outcome normalization and missing-data imputation.

#   efficient frontiers, covariance heatmaps, and confidence-interval forests
#   without deprecation warnings.
